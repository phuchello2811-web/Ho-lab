# HóaLab — Website dạy học Hóa học

Website mẫu tiếng Việt dành cho học sinh lớp 8–12, được xây dựng bằng HTML, CSS và JavaScript thuần, **không cần máy chủ, API hay thư viện bên ngoài**.

## Cách chạy

1. Giải nén thư mục `hoa-lab`.
2. Mở tệp `index.html` bằng Chrome, Safari, Edge hoặc Firefox.
3. Dùng menu để chuyển giữa các trang.

## Chức năng

- Trang tổng quan với lộ trình và tiến độ.
- 14 bài học cơ bản, có ghi chú, công thức, ví dụ; lọc theo khối lớp và tìm kiếm.
- Bảng tuần hoàn đủ **118 nguyên tố**, tương tác để xem thông tin.
- Bộ **27 câu hỏi trắc nghiệm**, chọn chủ đề, giải thích đáp án, chấm điểm.
- Mô phỏng pH (minh họa lý thuyết) và bài tập cân bằng 3 phương trình.
- Lưu bài học hoàn thành và kết quả trắc nghiệm vào `localStorage` trong trình duyệt.
- Giao diện responsive cho máy tính và điện thoại.

## Lưu ý

Đây là **bản demo học tập chạy ở frontend**, chưa có đăng nhập, quản trị viên, lớp học trực tuyến, video, tính năng AI, hay đồng bộ dữ liệu giữa thiết bị. Nếu triển khai làm sản phẩm chính thức, cần bổ sung backend, bảo mật, quản trị học liệu, kiểm duyệt nội dung và kết nối tên miền/hosting.

Giá trị pH là minh họa, không dùng để đánh giá an toàn hóa chất trong thực tế.

## Giao diện icon

Website sử dụng icon SVG dạng nét (inline, không có emoji và không phụ thuộc thư viện hoặc CDN).
